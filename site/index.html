    scene 04 · how a problem is built

    Brief → code → tests

    1. 01

      problem.md is the ticket

      Context, input/output, numbered requirements with a why, an assumptions section and documented limits.

    2. 02

      solution/ is the answer

      main.py carries the reasoning in its docstring, with runnable >>> examples, plus a thin CLI wrapper.

    3. 03

      tests/ is the proof

      Empty input, malformed input, ties, collisions, clock going backwards, threads, bytes split at every offset. 

    python scripts/run_tests.py        # 253 tests, 40 doctests
python scripts/build_catalog.py    # rebuild this page's data
